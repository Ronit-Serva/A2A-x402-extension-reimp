      FieldValueWhat it means

      Authorization → settlement → service

      A signature permits the specified token transfer. Verification checks it without moving tokens. The facilitator submits a transaction and pays ETH gas.

      Only confirmed settlement unlocks service computation. The AgentCard contract receives TestUSD; the client can pay while holding zero ETH.

      Why the block anchor?

      Restarting Hardhat creates a fresh in-memory chain. Addresses can repeat. The stored block hash and code hashes keep old configuration from being trusted on the wrong chain.

      Fixture versus this run

      The deploy script includes payment checks and restores 100 / 0 TestUSD. Its paymentTxHash belongs to that check. Each walkthrough has its own receipt above.
