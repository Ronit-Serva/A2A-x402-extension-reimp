# M3 — PASS, on-chain AgentCard

`npm run typecheck` and `npm run m3:check` passed on 2026-10-25. The full
sanitized card and check list are saved in `M3-result.json`.

The reader obtains A2A 1.0 JSON-RPC endpoint, statistics skill, required
extension URI, network, token, 2,000,000-unit amount, and AgentCard payTo from
the known contract via RPC. It validates the selected SDK card fields and
local payment profile. This is known-address card retrieval.

Actual contract calls proved authorized updates and withdrawal, unauthorized
update/withdrawal rejection, inactive-card rejection, and fixture restoration.
Wrong chain and missing-contract reads are rejected. The manifest now stores
token domain metadata, runtime code hashes and a seeded-block hash anchor so
chain resets can be distinguished even if addresses are reused. HTTP card
equivalence is checked in M4.
