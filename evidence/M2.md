Date: 2026-10-25. The facilitator runs as its own process on
`127.0.0.1:4022`; Hardhat runs separately on `127.0.0.1:8545`.

## Verified command

With a clean M1 deployment and fixture active:

```sh
npm run facilitator
npm run m2:check
```

`m2:check` passed. It confirms `/supported` advertises x402 v2 exact on
`eip155:31337`; `/verify` succeeds without changing token balances or
consuming the authorization; direct `/settle` rejects wrong pay-to, amount,
asset, and network; and two concurrent identical settle calls return the same
transaction identity while transferring exactly once. A changed payload under
the same payer/nonce key returns HTTP 409. An unfunded facilitator gas account
fails settlement without consuming the authorization or moving tokens. The
fixture is restored after the check.

The standalone process uses the installed `x402Facilitator` and
`ExactEvmScheme` APIs. It restricts every request to the manifest's local
network/token/card, the fixed 2,000,000-unit amount, and TestUSD EIP-712
domain name/version. Settlement calls SDK verify immediately before SDK
settle. It serializes identical authorization keys and atomically writes
sanitized settlement responses under ignored
`runtime/facilitator-settlements.json`.

The final facilitator signs transactions locally using its generated key in
ignored runtime/facilitator-key.json; it submits raw transactions through
loopback RPC. The server reads neither client nor facilitator key. Records are
namespaced under runtime/<deployment-block-hash>/facilitator-settlements.json.
M6 completed broadcast/hash-persistence crash reconciliation, restart tests,
and reset-generation checks; M7 reran this gate with that final implementation.
