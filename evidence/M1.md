# M1 — Local execution and token accounting

Date: 2026-10-25. Run from the Build directory on a freshly started Hardhat
node (chain 31337).

## Verified command

`npm run m1:local` passed. It deployed Counter, TestUSD, and AgentCard; incremented
Counter; performed a regular ERC-20 transfer and inspected its receipt; signed
an EIP-712 EIP-3009 authorization with an in-memory client key; submitted the
transfer from the separate facilitator account; and checked its receipt,
Transfer event, balances, and consumed nonce.

It also rejected a replay, an expired authorization, a forged signature, an
authorization exceeding the client's token balance, and an unauthorized
mint. The script asserted the token balances remained client=98,000,000 and
card=2,000,000 after those failures. The client had zero native ETH, and the
facilitator's native balance decreased after settlement.

The owner withdrew the card's 2,000,000 base units and minted 2,000,000 back to
the client to restore the fixture. The signer key is stored with mode 0600 in
ignored `runtime/client-key.json`; public metadata is saved in
`deployments/local.json`. The key is not printed here or in the command output.
